WCAG COMPLIANCE

The four accessibility principles

This portfolio was designed around the four WCAG principles: Perceivable, Operable, Understandable, and Robust.

P

Perceivable

Content is presented using readable text, clear headings, strong contrast, and descriptive labels. Images can use alternative text when added to the portfolio.

O

Operable

The navigation is keyboard-friendly, links have clear labels, buttons are easy to identify, and focus states are visible.

U

Understandable

The website uses simple language, consistent navigation, predictable layouts, and descriptive buttons and links.

R

Robust

Semantic HTML and responsive CSS are used to improve compatibility with modern browsers, different screen sizes, and assistive tools.
